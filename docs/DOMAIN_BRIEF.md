# Field Relay

Field Relay is a fictional, browser-only operations workbench for reviewing partner order CSV exports before a simulated delivery destination receives them. It demonstrates careful data ingestion, validation, routing and recoverable delivery operations. It does not connect to vendors, store data, send orders, or make compliance claims.

The useful proof is the deterministic core: quoted CSV parsing, explicit column mapping, retained source rows, safe exports, conflict quarantine, predictable routing, and a replay-safe delivery ledger. The interface must clearly say **Local simulation** and remain useful from phone through desktop.
